# 我的成长主页

这是一个用来记录大一学习经历、展示代码练习和课程作品的个人静态网站。项目用原生 HTML、CSS 和 JavaScript 编写，解压后可以直接用浏览器打开。

## 页面说明

| 文件 | 内容 |
| --- | --- |
| `index.html` | 关于我、AI / 前端 / 编程开发三个学习方向、技能代码和联系方式 |
| `records.html` | 三条学习记录。每条包含时间、学习内容、遇到的问题、解决方式，还可展开查看自测方法 |
| `projects.html` | 校园失物招领课程项目复盘。示例列表支持关键词搜索、按类型筛选和清除筛选 |
| `css/style.css` | 全站配色、布局、卡片样式和适配小屏幕的规则 |
| `js/main.js` | 作品页的筛选逻辑 |
| `assets/` | 首页插图 |

## 在本地运行

1. 解压项目压缩包，保持里面的文件和子文件夹在同一个项目目录。
2. 双击 `index.html`，或右键选择用浏览器打开。
3. 点击顶部导航切换页面。学习记录页可展开自测方法。项目作品页可输入“图书馆”，再切换到“招领”检查组合筛选。

项目使用相对路径，可以在 Windows 上直接打开，也可以用 VS Code 的 Live Server 扩展预览。修改文件并保存后，刷新页面即可看到变化。

## 修改成自己的版本

- 在 `index.html` 的“关于我”区修改学校、专业和自我介绍。联系方式区的 `hello@example.com` 是示例邮箱，请同时修改显示文字和 `mailto:` 地址。把 GitHub 入口中的 `https://github.com/` 替换为自己的个人主页，并更新两个联系方式的提示标签。
- 在 `records.html` 中修改时间和学习内容。新增记录时，可以复制一个完整的 `record-item`，保留四项记录字段。时间使用的是练习月份的上、中、下旬，可按实际日期细化。
- 在 `projects.html` 中修改项目经历。演示卡片的 `data-type="lost"` 对应“寻物”，`data-type="found"` 对应“招领”。筛选只处理页面里的示例数据，不向服务器提交信息。
- 在 `css/style.css` 的 `:root` 区修改颜色变量。首页技能卡片的代码用于展示，网页的筛选脚本位于 `js/main.js`。
- 上传 Git 仓库时，把本目录下的文件和文件夹一起放到仓库根目录，让 `index.html` 作为站点首页。目录名和文件名保留小写，避免发布后因大小写不同而找不到文件。
