项目作品

一次把课堂练习做成网页并发布上线的尝试。

校园失物招领

体验列表筛选 ↓
解决什么问题
把寻物和招领信息集中展示，让同学先看物品名称、地点和类型，再判断有没有自己要找的信息。
我的分工
整理展示字段，搭建页面和信息卡片，提交网页文件，并检查发布后的页面。
使用技术
原课程网页用 HTML 和 CSS 搭建，由 GitHub Pages 托管。下方演示另外用 JavaScript 实现关键词搜索和类别筛选。
遇到的最大困难
第一次发布时，页面在本地能打开，线上地址却访问不到。我先核对本地入口，再检查 Pages 的发布状态和链接，直到能从线上地址打开页面。
